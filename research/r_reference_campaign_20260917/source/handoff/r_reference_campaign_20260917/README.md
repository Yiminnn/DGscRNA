# R-reference PTC ablations and reviewer cohorts

This research campaign executes the recovered R algorithm and terminal legacy-style DL refinement on the fixed PTC cohorts and the previously approved 11 reviewer datasets. It extends `notebooks/dgscrna_results.ipynb`; no package defaults or website are changed.

`PLAN.md` freezes the experiment design, dataset roster, marker-context policy and interpretation limits. All scientific work runs in SLURM. The scripts retain the site's absolute project/environment paths, so this is a reviewable execution archive, not a portable Python package release.

The preparation stages are `export_datasets.py`, `build_markers.py`, `reference_prepare.R`, `ptc_ablation_prepare.R` and `ptc_geometry_only.R`. `reference_score.R` implements the four R clustering branches, R-compatible DEG statistics and the archived density rule. `terminal.py` calls the unchanged legacy MLP helper in `handoff/ptc_recovery_20260916/refine.py`. Per-condition labels, model weights, probabilities, histories and hashes are retained on HPC.

The R dbscan dependency uses the previously validated 64-bit MST-index patch (`results/hvg_ptc_20260916_v1/ptc_experiments/vendor_R_dbscan64`) to avoid overflow on larger cohorts. Density scoring uses observed cluster IDs to avoid losing a noiseless HDBSCAN group under the legacy 0-based indexing assumption. These safeguards, fixed curated cell sets and small-batch parameter caps are explicit adaptations. Software sessions and source versions are recorded; they are not claimed to be historical binary-identical environments.

`orchestrate.py` submits bounded SLURM jobs for scoring, terminal DL, evaluation, plots and audits. It stops neither the computation nor an incomplete arm at a queued state. Infrastructure errors require review/retry; no-op and scientifically untrainable states are explicit. `evaluate_unit.py` preserves curated semantic labels and separately named common-lineage endpoints; `ptc_abstention.py` adds Unknown-as-error metrics to the historical PTC binary mapping. This distinction matters because the historical mapping treats Unknown as non-T.

`checkpointed_deg.R` provides a recovery path for a timed-out full-gene DEG branch. It restricts only the installed Seurat `FindAllMarkers` outer identity loop, retaining the original function's tests, filtering, sorting and full expression input. Independent SLURM chunks save cluster outputs with input/source hashes; assembly restores the original cluster and DEG-row order. Its `validate` mode must reproduce every saved GBM DEG field and attribute exactly before recovery is allowed. The original active scorer is allowed to finish; no completed route is refitted for this optimization.

Already submitted scoring continuations also have an independent recovery receipt. The dispatcher reconciles a matching old route registration from that receipt on each tick, without submitting duplicate work or replacing a newer route attempt.

`audit_TTU_cluster_rng.R` investigates the parallel-RNG warning in the completed TTU all-gene UMAP-SNN run. Replaying the original coordinates and clustering settings reproduced the warning in `FindClusters`, while all six combinations of one/four workers and unset/42/2026 global seeds exactly reproduced all 44,149 saved cluster labels with Louvain seed 0. `audit_TTU_wilcox_kernel.R` separately reproduced 288 saved p-values across all 46 DEG-bearing clusters with three seeds and one/four workers; this is a sampled statistical check, not a full all-gene replay. The original warning log remains preserved. Delivery requires both audit records to pass and match the current DEG/cluster checksums.

`audit_unit.py` checks every saved terminal artifact and export. `audit_pre_guard_density.R` independently replays the unmodified original density function on early outputs, where per-job immutable source snapshots were not yet enabled. The source-transition record and failed attempts remain preserved. This audit confirms results, not unknowable transient file bytes. Per-job source guards freeze later R and terminal tasks. The already completed isolated-geometry preparations preceded their driver's guard; their source exception is explicit, and the transition copy records only the file observed when the guard was added.

`audit_ptc_density.R` verifies all 408 initial arms of the separate NMT/TTU CCA2000 runs against the original density function. `audit_ptc_marker_seed_coverage.py` links marker retention to the available DL class vocabulary. These diagnostics distinguish a missing marker from a competing panel or cutoff effect without changing any prediction or evaluation label.

Colorectal retains its full-cohort RNA fallback and adds `colorectal_CCA28_ge31`: a CCA feasibility sensitivity excluding the one three-cell donor, with 47,104 cells and the identical 12 marker libraries. `export_colorectal_CCA_control.py` records the donor-size-only exclusion; `colorectal_CCA_control.sbatch` runs four anchor workers with one BLAS thread each. The overall campaign contains 100 analysis units across the same 11 reviewer datasets and PTC.

`aggregate.py`, `plot_unit.py`, `plot_abstention.py` and `workflow_figure.py` create the full grid and figures. `report_and_notebook.py` executes only the new campaign cells, preserving all 153 earlier notebook cells. `finalize_campaign.sbatch` checks completion before staging and synchronizing to the explicitly authorized existing OneDrive path. Dense raw/prepared matrices, probability NPZs and model weights remain on HPC; every final prediction CSV is included in per-unit delivery archives with provenance.

`collect_slurm_accounting.py` records only campaign-referenced allocation/array-task jobs and their steps, including elapsed time, available MaxRSS, failed attempts and preserved logs. Running/pending rows are explicitly non-final. Delivery refreshes and packages this ledger. `record_delivery.py --upload-receipt` publishes `REMOTE_RECEIPT_UPLOADED.json` only after uploading and independently downloading the receipt with an exact SHA256 match; successful finalizer exit is checked separately through SLURM.

The original paper's saved Sup labels, the validated present-day refit, and fresh integrations are separate endpoints. Historical weights and the manuscript Accuracy calculation remain unresolved. HCL retains all 599,926 cells but is analyzed in its 59 original tissue groups; this is not a pooled 600k-cell clustering/scalability run. Descriptive best-on-test configurations do not establish universal optimality, and the grid is not fully factorial. No independent Pu cohort is used.
